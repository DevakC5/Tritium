# Binary Format (.tbc)

Tritium ByteCode — the serialized form of assembled ternary programs.

## Layout

```
Offset  Size  Field
0       4     Magic: "TBC\0"
4       4     Number of trytes (uint32, LE)
8       N*9   Tryte data (N trytes, 9 int8_t bytes each)
```

## Reading

1. Verify the 4-byte magic `TBC\0`
2. Read uint32 little-endian count
3. Read `count * 9` bytes of tryte data

## Writing

Generated by `trc --assemble <source.trc> <output.tbc>`.
Loaded by `trc --dump <file.tbc>` for disassembly.
